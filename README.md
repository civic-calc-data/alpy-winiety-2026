# Alpy Winiety 2026/2027 (Otwarte dane CSV)

Zestawienie urzędowych cen e-winiet i płatnych tuneli alpejskich dla aut osobowych do 3,5 t na sezon zimowy 2026/2027, przeliczonych na złotówki po średnim kursie NBP (tabela A nr `226/A/NBP/2026` z `2026-11-20`).

Pełny raport z opisem zasad i poradami dla kierowców znajduje się na stronie [sprawdztrase.pl/raporty/narty-w-alpach-2026-2027/](https://sprawdztrase.pl/raporty/narty-w-alpach-2026-2027/).

Plik danych: [`data/koszt-przejazdu-alpy-2026.csv`](data/koszt-przejazdu-alpy-2026.csv) (30 wierszy, kodowanie UTF-8).

## Słownik kolumn (`data/koszt-przejazdu-alpy-2026.csv`)

- `kategoria`: Typ wiersza (`winieta`, `odcinek_specjalny`, `trasa_narciarska_7d`).
- `kraj`: Kraj lub kierunek trasy narciarskiej.
- `pozycja`: Nazwa opłaty lub pakietu opłat dla danej trasy.
- `okres_lub_zakres`: Okres ważności winiety albo liczba przejazdów.
- `cena_waluta`: Kwota w walucie źródłowej (lub w PLN dla zsumowanych tras wielowalutowych).
- `waluta`: Kod ISO waluty (`CZK`, `EUR`, `CHF`, `PLN`).
- `kurs_nbp_pln`: Średni kurs NBP użyty do przeliczenia (1.0000 dla wierszy już zsumowanych w PLN).
- `cena_pln`: Kwota przeliczona na PLN z dokładnością do 0,01 zł.
- `tabela_nbp`: Numer oficjalnej tabeli kursów średnich NBP (`226/A/NBP/2026`).
- `data_nbp`: Data publikacji tabeli NBP (`2026-11-20`).
- `oficjalny_sklep`: Adres oficjalnego sklepu lub portalu operatora.
- `uwagi`: Istotne ograniczenia (np. 18-dniowa karencja w Austrii, zasady ważności, bramki we Włoszech).
